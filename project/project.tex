For \class, your total grade will be earned through multiple computational 
exercises as well as contribution to software projects, focused on advanced 
reactor modeling and simulation. This work will
include data collection, collaboration, and potential code contributions to 
tools in the ARFC ecosystem. \textbf{For 1 credit hour, the student should 
contribute a minimum of 4 hours of effort per week.}

This independent study is intended to provide an informative and hands-on experience with data science, reproducible scientific computing, and software development for nuclear engineering purposes. The primary role will be to work in a small team to coordinate and collaborate on the Python packages MoSDeN and Ghastly. In MoSDeN, work will primarily consist of adding unit tests, refactoring functions and classes, and using Sphinx to automatically generate documentation. In Ghastly, work will primarily consist of beta testing and aiding with dataset version control. For both MoSDeN and Ghastly, the student will also be expected to also assist with reviewing Pull Requests (PRs) and creating issues.
By the end of this independent study, the student will be expected to have gained experience with Python package development, version control with Git, and software testing and documentation. 
Data and software contributions resulting from this work will be contributed to
the open source repositories at \href{github.com/arfc}{github.com/arfc}. 
Deliverables will include: PRs the student created, PRs the student reviewed, issues the student created, and issues the student closed.


The student will be expected to consistently engage with the lead graduate 
student in this work as well as Prof. Huff. The deliverables will include 
commits to online code repositories as well as a final report and presentation summarizing accomplishments by 
the end of the semester. The project will be assessed as independent research work, much 
like a journal article undergoes peer review. I will be looking for : 

\begin{itemize}
\item Relevance
\item Technical Detail 
\item Analytic Rigor
\item Verifiability
\item Clarity
\item A Conclusion
\end{itemize}

This work will consist of four deliverables:

\begin{itemize}
        \item a work plan,
        \item completion of the Software Carpentry Git and GitHub training,
        \item collaborative code development toward software development in 
                MoSDeN and Ghastly,
        \item a brief summary report in the style of a conference or journal paper,
        \item and a 10 minute summary presentation.
\end{itemize}
